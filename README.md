# Juando

Web app (Chrome en Android) para el collar rastreador Juando: se conecta por Bluetooth al receptor
LoRa, muestra la posición del collar en un mapa offline y avisa cuando la batería del collar baja.

App: https://facumos.github.io/juando/

Mapas: © OpenStreetMap contributors (ODbL), teselas de Protomaps.
